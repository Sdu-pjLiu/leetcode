一家公司决定增加员工的薪水。

返回结果格式如下示例所示。

<b>示例 1:</b>

```
**输入：
** DataFrame employees
+---------+--------+
| name    | salary |
+---------+--------+
| Jack    | 19666  |
| Piper   | 74754  |
| Mia     | 62509  |
| Ulysses | 54866  |
+---------+--------+
**输出：
** +---------+--------+
| name    | salary |
+---------+--------+
| Jack    | 39332  |
| Piper   | 149508 |
| Mia     | 125018 |
| Ulysses | 109732 |
+---------+--------+
**解释：
** 每个人的薪水都被加倍。
```
