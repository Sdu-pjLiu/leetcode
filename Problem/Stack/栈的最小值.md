# [面试题 03.02. 栈的最小值](https://leetcode.cn/problems/min-stack-lcci/description/)

请设计一个栈，除了常规栈支持的pop与push函数以外，还支持min函数，该函数返回栈元素中的最小值。执行push、pop和min操作的时间复杂度必须为O(1)。<br>**示例：** 
```
MinStack minStack = new MinStack();
<br>minStack.push(-2);
<br>minStack.push(0);
<br>minStack.push(-3);
<br>minStack.getMin();   --> 返回 -3.
<br>minStack.pop();<br>minStack.top();      --> 返回 0.
<br>minStack.getMin();   --> 返回 -2.
```
