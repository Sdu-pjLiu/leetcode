# [845. 数组中的最长山脉](https://leetcode.cn/problems/longest-mountain-in-array/description/)

把符合下列属性的数组 <code>arr</code> 称为 **山脉数组**  ：

- <code>arr.length >= 3</code>
- 存在下标 <code>i</code>（<code>0 < i < arr.length - 1</code>），满足

- <code>arr[0] < arr[1] < ... < arr[i - 1] < arr[i]</code>
- <code>arr[i] > arr[i + 1] > ... > arr[arr.length - 1]</code>

给出一个整数数组 <code>arr</code>，返回最长山脉子数组的长度。如果不存在山脉子数组，返回 <code>0</code> 。

**示例 1：** 

```
**输入：** arr = [2,1,4,7,3,2,5]
**输出：** 5
**解释：** 最长的山脉子数组是 [1,4,7,3,2]，长度为 5。
```

**示例 2：** 

```
**输入：** arr = [2,2,2]
**输出：** 0
**解释：** 不存在山脉子数组。
```

**提示：** 

- <code>1 <= arr.length <= 10^4</code>
- <code>0 <= arr[i] <= 10^4</code>

**进阶：** 

- 你可以仅用一趟扫描解决此问题吗？
- 你可以用 <code>O(1)</code> 空间解决此问题吗？
