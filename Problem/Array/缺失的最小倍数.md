# [3718. 缺失的最小倍数](https://leetcode.cn/problems/smallest-missing-multiple-of-k/description/)

给你一个整数数组 <code>nums</code> 和一个整数 <code>k</code>，请返回从 <code>nums</code> 中**缺失的** 、**最小的正整数**  <code>k</code> 的**倍数** 。

**倍数**  指能被 <code>k</code> 整除的任意正整数。

<strong class="example">示例 1：** 

<div class="example-block">
**输入：**  nums = [8,2,3,4,6], k = 2

**输出：**  10

**解释：** 

当 <code>k = 2</code> 时，其倍数为 2、4、6、8、10、12……，其中在 <code>nums</code> 中缺失的最小倍数是 10。

<strong class="example">示例 2：** 

<div class="example-block">
**输入：**  nums = [1,4,7,10,15], k = 5

**输出：**  5

**解释：** 

当 <code>k = 5</code> 时，其倍数为 5、10、15、20……，其中在 <code>nums</code> 中缺失的最小倍数是 5。

**提示：** 

- <code>1 <= nums.length <= 100</code>
- <code>1 <= nums[i] <= 100</code>
- <code>1 <= k <= 100</code>
