# [3708. 最长斐波那契子数组](https://leetcode.cn/problems/longest-fibonacci-subarray/description/)

给你一个由**正** 整数组成的数组 <code>nums</code>。

**斐波那契** 数组是一个连续序列，其中第三项及其后的每一项都等于这一项前面两项之和。

返回 <code>nums</code> 中最长**斐波那契** 子数组的长度。

**注意:**  长度为 1 或 2 的子数组总是**斐波那契** 的。

**子数组** 是数组中**非空** 的连续元素序列。

<strong class="example">示例 1:** 

<div class="example-block">
**输入:**  nums = [1,1,1,1,2,3,5,1]

**输出:**  5

**解释:** 

最长的斐波那契子数组是 <code>nums[2..6] = [1, 1, 2, 3, 5]</code>。

<code>[1, 1, 2, 3, 5]</code> 是斐波那契的，因为 <code>1 + 1 = 2</code>, <code>1 + 2 = 3</code>, 且 <code>2 + 3 = 5</code>。

<strong class="example">示例 2:** 

<div class="example-block">
**输入:**  nums = [5,2,7,9,16]

**输出:**  5

**解释:** 

最长的斐波那契子数组是 <code>nums[0..4] = [5, 2, 7, 9, 16]</code>。

<code>[5, 2, 7, 9, 16]</code> 是斐波那契的，因为 <code>5 + 2 = 7</code>，<code>2 + 7 = 9</code>且 <code>7 + 9 = 16</code>。

<strong class="example">示例 3:** 

<div class="example-block">
**输入:**  nums = [1000000000,1000000000,1000000000]

**输出:**  2

**解释:** 

最长的斐波那契子数组是 <code>nums[1..2] = [1000000000, 1000000000]</code>。

<code>[1000000000, 1000000000]</code> 是斐波那契的，因为它的长度为 2。

**提示:** 

- <code>3 <= nums.length <= 10^5</code>
- <code>1 <= nums[i] <= 10^9</code>
