# [823. 带因子的二叉树](https://leetcode.cn/problems/binary-trees-with-factors/description/)

给出一个含有不重复整数元素的数组 <code>arr</code> ，每个整数 <code>arr[i]</code> 均大于 1。

用这些整数来构建二叉树，每个整数可以使用任意次数。其中：每个非叶结点的值应等于它的两个子结点的值的乘积。

满足条件的二叉树一共有多少个？答案可能很大，返回** 对 ** <code>10^9 + 7</code> **取余**  的结果。

**示例 1:** 

```
**输入:**  <code>arr = [2, 4]</code>
**输出:**  3
**解释:**  可以得到这些二叉树: <code>[2], [4], [4, 2, 2]</code>```

**示例 2:** 

```
**输入:**  <code>arr = [2, 4, 5, 10]</code>
**输出:**  <code>7</code>
**解释:**  可以得到这些二叉树: <code>[2], [4], [5], [10], [4, 2, 2], [10, 2, 5], [10, 5, 2]</code>.```

**提示：** 

- <code>1 <= arr.length <= 1000</code>
- <code>2 <= arr[i] <= 10^9</code>
- <code>arr</code> 中的所有值 **互不相同**
