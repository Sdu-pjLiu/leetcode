# [3950. 恰好一对连续置位](https://leetcode.cn/problems/exactly-one-consecutive-set-bits-pair/description/)

给你一个整数 <code>n</code> 。

如果其二进制表示中 **恰好 ** 仅包含 **一对**  **相邻的置位**  ，则返回 <code>true</code> ，否则返回 <code>false</code> 。
整数中的 **置位**  是指其 **二进制**  表示中的 <code>1</code> 。

<strong class="example">示例 1：** 

<div class="example-block">
**输入：**  n = 6

**输出：**  true

**解释：** 

- 6 的二进制表示为 <code>110</code> 。
- 恰好存在一对相邻的置位（<code>"11"</code>）。因此，答案为 <code>true</code> 。

<strong class="example">示例 2：** 

<div class="example-block">
**输入：**  n = 5

**输出：**  false

**解释：** 

- 5 的二进制表示为 <code>101</code> 。
- 不存在相邻的置位。因此，答案为 <code>false</code> 。

**提示：** 

- <code>0 <= n <= 10^5</code>
